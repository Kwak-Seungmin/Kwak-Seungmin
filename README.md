## Kwak Seung Min

**Technical Artist** — I break art production down into stages, find where it can be automated,
and build that into a pipeline that actually runs.

I work across art production and the tooling around it — designing art pipelines and putting
generative AI to practical use inside them. I'm less interested in producing one good result than
in building the standards and tools that make the same quality come out every time.

### What I work on

- **Asset generation pipeline** — Takes a game design document and produces concept art, 2D assets,
  and pixel sprites ready to drop into an engine without conversion. Each stage runs as an
  independent agent behind its own quality gate.
- **Evaluation rubric** — Scoring generated output on independent axes with no combined total, so a
  collapsed axis is never hidden behind the others.
- **AI short film pipeline** — An agent pipeline that carries scene images through color grading to
  a finished, edited film.

### Tools

`Maya` `ZBrush` `Substance Painter` `Unreal Engine` `Blender` `Codex` `Claude Code`
